🚀 INÍCIO RÁPIDO (3 PASSOS):

1️⃣  INSTALAR
   Windows: Clique duas vezes em "install.bat"
   Linux/Mac: Execute "./install.sh"

2️⃣  CONFIGURAR API (obrigatório para importar PDFs)
   • Acesse: https://console.groq.com/keys
   • Copie sua chave API GRATUITA
   • Crie arquivo ".env" com: GROQ_API_KEY=sua_chave_aqui
   • Teste: python teste_ia.py

3️⃣  EXECUTAR
   Windows: Clique duas vezes em "run.bat"
   Linux/Mac: Execute "./run.sh"

⚡ FUNCIONALIDADES PRINCIPAIS:

🤖 IMPORTAR PDFs COM IA
   • Clique em "🤖 Importar PDFs com IA"
   • Selecione múltiplos PDFs de fornecedores
   • Aguarde o processamento automático
   • ⚠️ IMPORTANTE: Sempre revise os dados extraídos!

📊 EDITAR DADOS
   • Clique nas células para editar
   • Use o zoom (slider no canto inferior direito)
   • Alterne tema Dark/Light (botão 🌓)

🔍 COMPARAR PREÇOS
   • Clique em "🔍 Comparar Preços"
   • Sistema analisa automaticamente
   • Melhor preço de cada produto fica em verde
   • Arquivo é salvo automaticamente

💾 SALVAR
   • Clique em "💾 Salvar"
   • Escolha local e nome do arquivo
   • Formato Excel com formatação profissional

📋 COLUNAS DO SISTEMA (destacadas em amarelo):

• FORNECEDOR - Nome do fornecedor
• PRODUTO - Nome do produto/insumo
• QUANTIDADE - Quantidade com unidade (ex: "1 KG", "500 G")
• PREÇO - Valor em reais (apenas número, ex: 150.00)
• VALIDADE - Data de validade (DD/MM/YYYY)
• ORIGEM - País de origem (Brasil, China, Índia, etc)

💡 DICAS PRO:

✓ Use PDFs com texto selecionável (não escaneados)
✓ Processe 5-10 PDFs por vez para melhor performance
✓ SEMPRE revise os dados antes de salvar (IA ~95% precisão)
✓ Mantenha a API Key segura (não compartilhe)

❓ PROBLEMAS COMUNS:

❌ "API Key não configurada"
   → Crie arquivo .env com GROQ_API_KEY=sua_chave
   → Teste com: python teste_ia.py

❌ "Erro ao processar PDF"
   → Verifique se PDF tem texto selecionável
   → Tente processar um por vez

❌ "Dados extraídos incorretos"
   → Normal! IA tem ~5% de erro
   → Sempre revise antes de salvar
