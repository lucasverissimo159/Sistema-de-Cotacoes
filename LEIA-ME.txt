# Sistema de Cotações Pro v3.1 - AI Edition

Sistema completo para comparação de cotações com processamento inteligente de PDFs usando IA.

## 📦 Arquivos Incluídos

### Arquivos Python (.py)
- **app.py** - Arquivo principal para executar a aplicação
- **main_window.py** - Interface gráfica principal
- **config.py** - Configurações do sistema
- **data_manager.py** - Gerenciamento de dados Excel
- **pdf_processor.py** - Processador de PDFs com IA
- **table_model.py** - Modelo de tabela para interface
- **styles.py** - Estilos Figma-style (Dark/Light theme)
- **teste_ia.py** - Script para testar configuração da API

### Scripts de Instalação/Execução
- **install.bat** - Instalador Windows
- **install.sh** - Instalador Linux/Mac
- **run.bat** - Executar no Windows
- **run.sh** - Executar no Linux/Mac

### Configuração
- **.env.example** - Exemplo de configuração de API Key
- **requirements.txt** - Dependências Python
- **.gitignore** - Arquivos a ignorar no Git

## 🚀 Como Usar

### 1. Instalar Dependências

**Windows:**
```cmd
Clique duas vezes em: install.bat
```

**Linux/Mac:**
```bash
chmod +x install.sh
./install.sh
```

### 2. Configurar API Groq (OBRIGATÓRIO para importar PDFs)

1. Acesse: https://console.groq.com/keys
2. Crie uma conta gratuita
3. Copie sua API Key
4. Crie arquivo `.env` com:
```
GROQ_API_KEY=sua_chave_aqui
```

### 3. Testar Configuração

```bash
python teste_ia.py
```

### 4. Executar Sistema

**Windows:**
```cmd
Clique duas vezes em: run.bat
```

**Linux/Mac:**
```bash
chmod +x run.sh
./run.sh
```

## 📋 Estrutura de Dados

O sistema espera as seguintes colunas (destacadas em amarelo no Excel):

- **FORNECEDOR** - Nome do fornecedor
- **PRODUTO** - Nome do produto/insumo
- **QUANTIDADE** - Quantidade com unidade (ex: "1 KG")
- **PREÇO** - Valor em reais (numérico)
- **VALIDADE** - Data de validade (DD/MM/YYYY)
- **ORIGEM** - País de origem

## 💡 Dicas Importantes

1. **Revise os dados extraídos** - A IA tem ~95% de precisão
2. **Use PDFs com texto selecionável** - Melhor extração
3. **Processe 5-10 PDFs por vez** - Mais eficiente
4. **Mantenha API Key segura** - Não compartilhe

## 🆘 Problemas Comuns

### API Key não funciona
```bash
python teste_ia.py
```
Verifique se a chave está correta.

### Erro ao processar PDF
- Verifique se o PDF contém texto selecionável
- Tente processar um PDF por vez para identificar o problema

### Dados extraídos incorretos
- SEMPRE revise os dados antes de salvar
- A IA pode ter ~5% de erro
